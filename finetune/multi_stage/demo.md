### 5. Демонстрация пайплайна вживую (2 мин)

**Запуск демонстрации (покажет все 3 этапа):**

```bash
cd /mnt/f/git/advanced && PYTHONPATH=. python3 finetune/multi_stage/demo_pipeline.py
```

**Пример вывода:**
```
============================================================
  ОТЗЫВ: ПОЗИТИВНЫЙ
============================================================
  «Отличный товар! Быстрая доставка, рекомендую всем!»

📊 STAGE 1 — Анализ
   Позитивные маркеры: ['отличный', 'быстрая', 'рекомендую']
   Негативные маркеры: []
   Слов: 7, язык: ru

🎯 STAGE 2 — Классификация
   Категория: позитивный (уверенность: 0.92)

✅ STAGE 3 — Валидация
   Валидно: True
   Финальная категория: позитивный
   Финальная уверенность: 0.92

🏁 ИТОГ: позитивный | 0.92
```

**Что объяснить аудитории:**

| Этап | Что делает | Что показывает |
|------|------------|----------------|
| **Stage 1** | Извлекает маркеры | `positive: ['отличный', 'рекомендую']`, `negative: []` |
| **Stage 2** | Считает баланс | positive > negative → `позитивный` |
| **Stage 3** | Валидирует JSON | 4 категории, уверенность 0.0-1.0, `validated: true` |

**Преимущество подхода:**
- ✅ **Интерпретируемость** — видно, почему принято решение (маркеры)
- ✅ **Модульность** — можно улучшить каждый этап отдельно
- ✅ **Контроль** — Stage 3 отбракует невалидные выводы

### 6. Гибридный режим с GPUStack (1 мин)

**Показать конфигурацию:**
```bash
cd /mnt/f/git/advanced && cat finetune/multi_stage/.env.example
```

**Ожидаемый вывод:**
```
# GPUStack API endpoint
GPUSTACK_API_URL=https://gpustack.data.lmru.tech
AI_API_KEY=your-api-key-here

# Ollama configuration (local)
OLLAMA_API_URL=http://localhost:11434
OLLAMA_MODEL=qwen3:14b
```

**Запустить гибридный пайплайн:**
```bash
cd /mnt/f/git/advanced && PYTHONPATH=. python3 -c "from finetune.multi_stage.hybrid_pipeline import run_hybrid; r = run_hybrid('Товар хороший, но доставка задержалась.'); print('Stage 1:', r['sources']['stage1']); print('Stage 2:', r['sources']['stage2']); print('Stage 3:', r['sources']['stage3']); print('Итог:', r['final_result']['category'])"
```

**Ожидаемый вывод:**
```
Stage 1: ollama
Stage 2: ollama
Stage 3: gpustack
Итог: нейтральный
```

**Что объяснить:**
- **Этапы 1-2**: локально (Ollama, qwen3:14b) — быстро и дёшево
- **Этап 3**: облако (GPUStack, qwen3.6-27b) — валидация мощной моделью
- **Баланс**: экономия на простых этапах + точность на финальном

## ⚠️ Примечания для демонстратора

1. **Точность низкая** — это ожидаемо для rule-based классификатора без fine-tuning
2. **Гибридный режим** требует настроенных `GPUSTACK_API_URL` и `AI_API_KEY` в `.env`
3. **Графики** генерируются в `finetune/multi_stage/charts/` — открыть их заранее
4. **Все команды однострочные** — копируй и вставляй без редактирования
