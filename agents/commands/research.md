**Запрос пользователя**: $ARGUMENTS

**ВЫПОЛНЯЙ ИССЛЕДОВАНИЕ НАПРЯМУЮ — не делегируй через task().**

**ПЕРЕД началом исследования:**
- Внимательно изучи `AGENTS.md` и `README.md` в корне проекта
- Используй их как авторитетный источник архитектуры и соглашений

Твой workflow:

1. **EXPLORE**: Используй codegraph_explore, codegraph_search, grep для поиска паттернов
2. **ANALYZE**: Изучи архитектуру, зависимости, ключевые компоненты
3. **SYNTHESIZE**: Структурируй находки — файлы, паттерны, связи
4. **REPORT**: Отчёт пользователю:
   - Что найдено (файлы, символы, паттерны)
   - Архитектура (как работает, связи между компонентами)
   - Рекомендации (если уместно)

**Инструменты:**
- `codegraph_explore` — основной инструмент (вербатим источник + call path)
- `codegraph_search` — поиск символов по имени
- `codegraph_node` — чтение файлов + blast radius
- `grep`, `glob` — для текст-поиска

**Ограничения:**
- НЕ используй `task()` для делегирования — ты уже агент research
- НЕ запускай параллельные задачи — работай в текущей сессии
- Возвращай структурированный отчёт с путями к файлам
